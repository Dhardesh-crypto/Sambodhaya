คู่มือผู้แก้ไขเนื้อหา วัดสัมโพธายะEditor guide · Sambodhaya

คู่มือนี้อธิบายวิธีแก้ไขเนื้อหาของเว็บไซต์วัดสัมโพธายะ (บทเรียน ป้าย กระดานในศาลา และการ์ดความรู้ในวัด 3 มิติ) ผ่านหน้าแก้ไขเนื้อหา โดยไม่ต้องเขียนโค้ด ทุกครั้งที่บันทึก การเปลี่ยนแปลงจะขึ้นเว็บไซต์เองภายในประมาณหนึ่งนาที

This guide explains how to edit what the Sambodhaya website says (the lessons, the signs, the hall boards and the info cards in the 3D temple) through the content admin, without any code. Each time you save, the change goes live by itself in about a minute.

1เริ่มต้นใช้งาน · Getting started

สิ่งที่ต้องมี

  • บัญชี GitHub (สมัครฟรีที่ github.com)
  • คำเชิญจากผู้ดูแลเว็บไซต์ ให้เข้าร่วมคลังข้อมูล Sambodhaya ซึ่งจะส่งมาทางอีเมล กด Accept invitation ในอีเมลนั้น

เข้าสู่ระบบ

  1. เปิด sambodhaya.netlify.app/admin
  2. กด Sign In with GitHub
  3. ครั้งแรกเท่านั้น GitHub จะถามว่าอนุญาต Sambodhaya admin หรือไม่ ให้กด Authorize

เมื่อเข้าได้แล้ว ด้านซ้ายจะมี Lessons Temple (3D) และ Library

What you need

  • A GitHub account (free at github.com)
  • An invitation from the site's caretaker to the Sambodhaya repository; it comes by e-mail: press Accept invitation in it

Signing in

  1. Open sambodhaya.netlify.app/admin
  2. Press Sign In with GitHub
  3. The first time only, GitHub asks whether to allow Sambodhaya admin: press Authorize

Once in, you see Lessons, Temple (3D) and Library on the left.

2สิ่งที่แก้ไขได้ · What you can edit

  • Lessons บทเรียน U01–U08: ชื่อเรื่อง คำถาม เรื่องสั้น ในชีวิตประจำวัน หมายเหตุต่าง ๆ แหล่งที่มา สถานะการตรวจ และแบบฝึกหัด
  • Temple (3D) วัด 3 มิติ: ชื่อและคำบรรยายของศาลา (Hall names & subtitles) ป้าย (Signs) กระดานในศาลา (Hall boards) การ์ดความรู้ (Info cards) และคำบรรยายภาพเรื่องราวทั้งแปด (Story paintings)
  • Library ห้องสมุด: รายการแหล่งที่มา (Sources) และหมายเหตุ AMBER กับคำบรรยายภาพวงล้อ
สิ่งที่ แก้ไขที่นี่ไม่ได้ โดยตั้งใจ: ข้อมูลบัญชีธนาคารและพร้อมเพย์ ชื่อพระอาจารย์ และปุ่มหรือเมนูของเว็บไซต์ หากต้องการเปลี่ยน ให้ติดต่อผู้ดูแลเว็บไซต์
  • Lessons U01–U08: title, question, the short story, everyday life, the notes, sources, checking status and the exercises
  • Temple (3D): hall names and subtitles (Hall names & subtitles), signs (Signs), the boards in the halls (Hall boards), the info cards (Info cards) and what the eight story paintings show (Story paintings)
  • Library: the source list (Sources), the AMBER notes and the description of the wheel image
What you can't edit here, on purpose: the bank and PromptPay details, the monks' names, and the site's buttons and menus. To change those, contact the site's caretaker.

3แก้ไขและบันทึก · Editing and saving

  1. เลือกหมวดด้านซ้าย แล้วเลือกรายการที่ต้องการ เช่น U03 · Trying a path that was too harsh
  2. ข้อความทุกช่องมีสองกล่อง: ไทย · Thai และ English แก้ไขทั้งสองภาษาให้ตรงกัน
  3. บางส่วนพับเก็บไว้ กดลูกศร › เพื่อเปิด
  4. กด Save ที่มุมขวาบน จะขึ้นข้อความ Entry saved.
  5. รอประมาณหนึ่งนาที แล้วโหลดหน้าเว็บไซต์ใหม่ (หรือเข้าวัด 3 มิติใหม่) เพื่อดูการเปลี่ยนแปลง

ทุกครั้งที่บันทึก ระบบจะเก็บไว้ว่าใครแก้อะไร เมื่อไร จึงย้อนกลับได้เสมอ

  1. Choose a section on the left, then the item, e.g. U03 · Trying a path that was too harsh
  2. Every text has two boxes: ไทย · Thai and English. Keep both languages saying the same thing.
  3. Some parts are folded away: press the arrow › to open them.
  4. Press Save at the top right; Entry saved. appears.
  5. Wait about a minute, then reload the website (or enter the 3D temple again) to see the change.

Every save records who changed what and when, so a change can always be undone.

4หลักการสำคัญ · Rules to keep

  • กรอกทั้งสองภาษาเสมอ ข้อความใดที่มีภาษาไทย ต้องมีภาษาอังกฤษด้วย และกลับกัน (ยกเว้นช่องที่ไม่บังคับ ซึ่งเว้นว่างทั้งสองภาษาได้)
  • อย่าเปลี่ยนรหัสบทเรียน (Code เช่น U03) เว็บไซต์และวัด 3 มิติหาบทเรียนจากรหัสนี้
  • แหล่งที่มา ช่อง Source key ต้องเป็นรหัสที่มีอยู่ใน Library → Sources เช่น MN26
  • คำตอบที่ถูกในแบบฝึกหัด นับจาก 0: 0 = ตัวเลือกแรก 1 = ตัวเลือกที่สอง
  • การ์ดพระแก้วมรกต คำว่า {season} จะถูกแทนด้วยฤดูปัจจุบันโดยอัตโนมัติ อย่าลบออก
  • เนื้อหาคำสอนภาษาไทย ต้องตรงกับห้องสมุด (Library ใน Notion) ให้แก้ที่ห้องสมุดก่อน แล้วจึงแก้ที่นี่ ภาษาอังกฤษเป็นฉบับร่างที่แปลโดย AI และแสดงว่ายังไม่ได้ตรวจ
  • ป้ายในวัด 3 มิติ ควรสั้น ข้อความยาวเกินไปจะตัดหรือย่อเล็กลง
  • หากสองคนแก้ไขรายการเดียวกันพร้อมกัน คนที่บันทึกทีหลังอาจต้องโหลดใหม่และแก้อีกครั้ง ตกลงกันก่อนว่าใครแก้ส่วนไหน
  • Always fill in both languages. A text with Thai needs English too, and the other way round (an optional field may be left empty in both).
  • Don't change a lesson's code (Code, e.g. U03): the website and the 3D temple find the lesson by it.
  • Sources: a Source key must be one listed in Library → Sources, e.g. MN26.
  • The right answer of an exercise is counted from 0: 0 = the first option, 1 = the second.
  • The Emerald Buddha card: {season} is filled in with the current season by itself; don't remove it.
  • The Thai teaching text must match the Library (in Notion): correct it there first, then here. The English is an AI draft translation and is shown as unreviewed.
  • Signs in the 3D temple should be short; long text gets cut or shrinks.
  • If two people edit the same item at once, the one who saves second may have to reload and redo the change. Agree beforehand who edits what.

5ถ้าการแก้ไขไม่ขึ้นเว็บไซต์ · If a change doesn't appear

  1. รอ 1–2 นาที แล้วโหลดหน้าใหม่ (บางครั้งเบราว์เซอร์จำหน้าเก่าไว้)
  2. หากยังไม่ขึ้น แสดงว่าระบบตรวจเนื้อหาได้หยุดการเผยแพร่ไว้ เว็บไซต์จะยังแสดงฉบับก่อนหน้าตามปกติ จึงไม่มีอะไรเสียหาย
  3. สาเหตุที่พบบ่อย: ข้อความภาษาไทยหรืออังกฤษว่างไว้ หรือใช้รหัสแหล่งที่มาที่ไม่มีอยู่
  4. เปิดรายการนั้น แก้ให้ถูก แล้วบันทึกอีกครั้ง หากไม่แน่ใจ แจ้งผู้ดูแลเว็บไซต์ว่าแก้อะไร และเวลาที่บันทึก
  1. Wait 1–2 minutes and reload (sometimes the browser keeps the old page).
  2. If it still doesn't show, the content check has held the change back. The website keeps showing the previous version, so nothing breaks.
  3. Common causes: a Thai or English text left empty, or a source key that doesn't exist.
  4. Open the item, correct it and save again. If you're unsure, tell the site's caretaker what you changed and when you saved.

6แก้ไขผิดพลาด · Undoing a mistake

  • วิธีที่ง่ายที่สุด: เปิดรายการนั้น แก้กลับเป็นข้อความเดิม แล้วบันทึก
  • หากจำข้อความเดิมไม่ได้ ผู้ดูแลเว็บไซต์ย้อนกลับได้จากประวัติใน GitHub ทุกการบันทึกมีชื่อว่า Update … พร้อมชื่อผู้แก้และเวลา
  • The simplest way: open the item, change the text back and save.
  • If you don't remember the old text, the site's caretaker can restore it from the history on GitHub: every save is listed as Update … with who made it and when.

7ความปลอดภัย · Keeping it safe

  • อย่าให้ผู้อื่นใช้บัญชี GitHub ของคุณ และตั้งการยืนยันตัวตนสองชั้น (2FA) ในการตั้งค่าของ GitHub
  • บนคอมพิวเตอร์ที่ใช้ร่วมกัน ให้ออกจากระบบเมื่อเสร็จ: กดรูปโปรไฟล์มุมขวาบน แล้วเลือก Sign Out
  • สิทธิ์ของคุณใน GitHub ใช้แก้โค้ดของเว็บไซต์ได้ด้วย ให้แก้เฉพาะในหน้าแก้ไขเนื้อหาเท่านั้น
  • Don't let anyone else use your GitHub account, and turn on two-factor authentication (2FA) in your GitHub settings.
  • On a shared computer, sign out when you're done: press your picture at the top right and choose Sign Out.
  • Your access on GitHub would also let you change the website's code: only edit through the content admin.
